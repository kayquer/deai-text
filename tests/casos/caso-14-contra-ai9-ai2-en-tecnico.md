## entrada
Each node in the tree represents the state of the board after one legal move. Children are ordered by the evaluation function, best first, so alpha-beta prunes earlier.

Use the arrow keys to navigate the tree in the debugger. Left collapses a subtree, right expands it. The status bar shows the node count and the current depth.
